# jihoo-site

A tiny personal page built with [Astro](https://astro.build).

## What's here

- Terminal-styled sections: `whoami`, rig (laptop/desktop specs), and stack (language/interests).
- A mascot easter egg (`public/mascot.png`) that randomly peeks in from a screen edge with a
  speech-bubble one-liner, and darts away across the screen if you click it before it retreats.

## Run it

```bash
npm install
npm run dev      # http://localhost:4321
```

## Build for production

```bash
npm run build    # outputs static site to ./dist
npm run preview  # preview the production build locally
```

Deploy the contents of `dist/` anywhere that serves static files (GitHub Pages, Netlify, Vercel, etc).
